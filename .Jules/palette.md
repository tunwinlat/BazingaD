## 2026-03-18 - Added Clear Search Button to Unified Search
**Learning:** Returning focus to an input field after an action (like clearing the text) ensures that keyboard-only users don't lose their context and can continue typing immediately, improving the overall interaction flow and reducing friction.
**Action:** Always verify focus management when adding interactive elements that manipulate or reset the state of a primary input field. Include `aria-label` attributes on newly added icon-only buttons.
