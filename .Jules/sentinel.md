## 2024-05-24 - SSRF Bypass via Integer/Hexadecimal IPs
**Vulnerability:** The `isSafeUrl` function used `new URL(url).hostname` to extract the hostname, but relied purely on matching dotted-decimal IP patterns and known hostnames to block private/local addresses. This allowed SSRF bypasses via integer (e.g., `2130706433` -> `127.0.0.1`) and hexadecimal (`0x7f000001`) IP representations, as `new URL` parses them successfully but the resulting hostname string retains its numeric form and evades regex checks.
**Learning:** `new URL` in Node.js/browsers does not always normalize numeric IP formats into standard IPv4 dotted-decimal format in the `hostname` property, enabling SSRF payloads to slip past naive string-based blocklists.
**Prevention:** Explicitly reject hostnames consisting entirely of digits (`/^\d+$/`) or hexadecimal strings (`/^0x[0-9a-f]+$/i`) immediately after URL parsing, before performing specific blocklist comparisons.
